01 — 프로젝트 개요

골프 예약 서비스의 모든 요청은 보안 경계를 지난다

프로젝트 개요

예약 기능 위에 개인정보 마스킹, 인젝션 차단, API 모니터링, 접근 감사를 겹쳐 둡니다.

챗봇 예약

DeepSeek는 DB에 직접 접근하지 않고, 서버가 다시 검증한 tool을 통해 createBooking()으로 합류합니다.

수동 예약

POST /api/bookings는 createBooking() 단일 진입점과 잠금 기반 DB 함수를 사용합니다.

인젝션 차단

chatGuard가 LLM 호출 전에 차단하고, 보안 이벤트·Discord 알림·거부 감사를 각각 남깁니다.

예약번호 열거 탐지

예약번호와 전화번호를 함께 대조하고, 실패가 쌓이면 ANO_CODE_ENUM을 만듭니다.

운영 메트릭

api_logs와 security_events를 같은 시간축으로 집계하고, 세 겹의 권한 검사로 접근을 제한합니다.

Critical IP 조사

일반 로그는 IP 해시만, critical 이벤트는 30일 암호문을 보관하고 admin 사유와 감사 기록 뒤에만 복호화합니다.
