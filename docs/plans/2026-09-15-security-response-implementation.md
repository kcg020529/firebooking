# 보안 탐지·대응 구현 계획

1. 규칙 메타데이터 테스트를 추가하고 공격 분류, 한글 이름, 명확한 심각도 기준을 구현한다.
2. 주민번호·카드번호 탐지 테스트를 제거하고 PII 구현·문서·계약을 정리한다.
3. 이메일 검증 테스트를 추가하고 서버 회원가입 API와 화면 연동을 구현한다.
4. IP 블랙리스트·Cloudflare 동기화 테스트와 DB 마이그레이션을 먼저 작성한 뒤 서비스 계층을 구현한다.
5. 관리자 차단·해제 API와 로그인 차단 검사를 구현하고 감사 기록을 추가한다.
6. 로그인 제한 키를 이벤트와 연결하고 관리자 잠금 해제 API를 구현한다.
7. 관리자 비인가 접근 반복 횟수 탐지와 자동 차단을 구현한다.
8. 보안 API 집계를 확장하고 서버 상태, 공격 그래프, 규칙 색상과 차단 관리 UI를 구현한다.
9. `CLAUDE.md`, `AGENTS.md`, `docs/SECURITY.md`, 환경변수 예시와 스키마 원본을 갱신한다.
10. 단위 테스트, 린트, 프로덕션 빌드를 실행해 회귀를 확인한다.
